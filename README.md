# ABSOLUTE CINEMA (X-MEDIA)

Next-generation media player for Windows 7 and 8/8.1 with 4K/8K playback, audio-reactive speaker walls, and an original cinematic intro/outro.

## Status
Early planning. Folder layout, design docs and a motion prototype of the intro are in place. Source code is not started; the technology stack is still to be chosen (see docs/WINDOWS_COMPATIBILITY.md).

## Key features (planned)
- 4K/8K video playback with optional motion interpolation
- 8 speaker cabinets (4 left, 4 right), 16 woofer drivers, audio-reactive cone physics
- Slide-out speaker walls so the video can expand
- Cinematic intro/outro over the last-used visualizer
- Skins, visualizers, custom startup sounds

See `docs/` for details. Open `docs/prototypes/intro-prototype.html` in a browser to see the intro motion.
